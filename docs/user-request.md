# Polished Project Request



Give me another large, deliberately open-ended electronics and KiCad task like the previous exercise. Define only the supply voltage \*\*E\*\*, the desired total current \*\*It\*\*, and the approximate LED forward voltage \*\*Vf\*\*. Do not give me the topology, resistor values, branch currents, or PCB arrangement.
I will perform the circuit calculations myself, decide the series/parallel topology, choose the resistor values, create the complete KiCad schematic, assign footprints, design and route the PCB, add the board outline and silkscreen, run ERC/DRC and schematic-to-PCB parity checks, and inspect the final board in 3D.
Keep the challenge limited to components and concepts already covered: resistors, LEDs, a two-pin power connector, supply rails, ground, series circuits, parallel circuits, Ohm's law, current splitting, voltage drops, and resistor power.
This should be my second major independent electronics project, so the task should contain enough ambiguity to force me to make the engineering decisions myself.

The original request was informal and conversational; this version preserves the same intent while making it suitable for project documentation.
