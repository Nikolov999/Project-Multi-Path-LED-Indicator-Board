# Project Brief

## Origin

This learning challenge was generated by **ChatGPT (OpenAI, GPT-5.6 Sol)** during a guided electronics/KiCad study session.

The brief was intentionally open-ended. The repository author was expected to make the topology, calculation, component-value, schematic, and PCB-layout decisions independently.

The original exercise mentioned four LEDs. This documented version has been revised to **six LEDs** so that it accurately matches the implemented project.

---

## Given electrical values

Only these design values are fixed:

```text
Supply voltage:       E = 9 V
Desired total current: It ≈ 24 mA
LED forward voltage:   Vf ≈ 2 V per LED
```

---

## Functional requirement

Design a through-hole PCB containing:

- 6 LEDs
- resistors as required by the chosen topology
- 1 × 2-pin power connector

The board must illuminate all six LEDs from the 9 V supply.

### Constraints

- Create more than one current path between +9 V and GND.
- At least one path must contain multiple LEDs in series.
- The six LEDs must not simply be six identical resistor-and-LED branches.
- Every LED must be part of a current-limited arrangement.
- Target total current is approximately 24 mA.
- Total current must remain below 30 mA.
- No resistor should operate close to its power rating.
- Use only previously covered components:
  - resistors
  - LEDs
  - 2-pin connector
  - +9 V / GND
  - PWR_FLAG
- Use through-hole footprints.
- Use a 2-layer PCB, although both copper layers do not need to be used.
- Add useful silkscreen including the board name, 9 V, GND, and component identification.
- The PCB should be visually organized so the circuit structure can be followed.

---

## Independent work required

Before opening KiCad:

1. Invent the circuit topology.
2. Identify every complete path from +9 V to GND.
3. Identify series and parallel sections.
4. Determine the voltage drop across every resistor.
5. Choose branch currents.
6. Calculate every required resistor value.
7. Calculate every LED current.
8. Calculate total supply current.
9. Calculate resistor power dissipation.
10. Record important node voltages.

Then complete the full KiCad workflow:

1. Create the schematic.
2. Verify LED anode/cathode orientation.
3. Add power symbols and PWR_FLAG declarations.
4. Run ERC.
5. Assign through-hole footprints.
6. Update the PCB from the schematic.
7. Place components intentionally.
8. Draw Edge.Cuts.
9. Route all nets.
10. Add silkscreen.
11. Run DRC.
12. Run schematic/PCB parity checks.
13. Inspect the board in the 3D Viewer.
14. Generate fabrication outputs.

---

## Deliberate difficulty

The task is designed to expose mistakes such as:

- using the full 9 V in Ohm's law when a resistor does not actually have 9 V across it;
- forgetting that series LED voltage drops add;
- forgetting that parallel branches share voltage;
- confusing total branch current with the current through an individual LED after a junction;
- overlooking the voltage already lost before a downstream component;
- exceeding the current budget;
- assuming parallel LEDs always share current equally.

No topology or resistor values are supplied by the brief.
