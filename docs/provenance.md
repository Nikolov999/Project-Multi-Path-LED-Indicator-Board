# Project Provenance

This repository documents an educational PCB project developed during a guided ChatGPT study session.

- **Exercise brief:** generated by ChatGPT (OpenAI, GPT-5.6 Sol).
- **Project implementation:** performed by the repository author.
- **Review:** iterative discussion with ChatGPT was used to identify issues such as LED polarity and to review the circuit calculations.
- **Final design choice:** the author extended the original exercise into a six-LED, three-branch mixed series/parallel board.

The repository intentionally distinguishes the AI-generated exercise brief from the author's implementation.
